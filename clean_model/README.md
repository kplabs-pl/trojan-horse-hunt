This is to output directory for the `train_clean_model.py` script.

The official clean model used in the competition can be downloaded from [https://www.kaggle.com/models/kp-labs/clean-nhits-model/PyTorch/default](https://www.kaggle.com/models/kp-labs/clean-nhits-model/PyTorch/default). Place the .pt and .cpkt files in this directory. **Important! To download the model, you must be a registered Kaggle user and accept the competition rules.**
